# 🎨 NGUI学习

> [!NOTE] 什么是 NGUI？
> NGUI（Next-Gen UI）是 Unity 中一款经典的**第三方 UI 插件**（在 UGUI 出现之前是最主流的选择）。它提供了强大的 UI 制作工具，至今仍有许多老项目在使用。其核心设计理念——**锚点系统**、**图集管理**、**分辨率自适应**——深刻影响了后来 UGUI 的设计。

---

## 🧱 三大基础组件

> NGUI 的 UI 体系建立在三个核心组件之上，它们层层协作构成了完整的 UI 系统。

---

### 🌳 Root 组件

> Root 是用于**分辨率自适应**的根对象，是整个 NGUI UI 层级的起点。

| 职责 | 说明 |
|------|------|
| **设置基准分辨率** | 相当于设置 UI 显示区域的标准尺寸 |
| **管理自适应** | 管理所有 UI 控件在不同分辨率下的缩放适配 |
| **充当 UI 画布** | 类似一个画布，所有 UI 都显示在这个画布上 |

可以简单理解成：==它管理一个 UI 画布，所有的 UI 都是显示在这个画布上的，并且负责 UI 画布和不同屏幕分辨率的适应关系。==

---

#### RootStyle（根样式）

> RootStyle 决定了 UI 如何响应屏幕分辨率的变化。

##### Flexible（灵活模式）

> 在该模式下，UI 都是以**像素为基础**，100 像素的物体无论在多少分辨率上都是 100 像素。

| 特性 | 说明 |
|------|------|
| **基准原则** | 像素大小绝对不变 |
| **问题** | 100 像素在低分辨率上显示正常，但在高分辨率上会显得很小 |

| 参数 | 说明 |
|------|------|
| **Minimum Height** | ==最小高度== —— 屏幕小于该高度时，UI 会自动缩放保持原有比例 |
| **Maximum Height** | ==最大高度== —— 屏幕大于该高度时，UI 会自动缩放保持原有比例 |

> [!TIP] 理解 Min/Max Height
> 这两个参数定义了一个"安全范围"：屏幕高度在此范围内时 UI 保持原始像素大小，超出范围则按比例缩放。这样可以避免 UI 在极端分辨率下过小或过大。

##### Constrained（约束模式）

> 该模式下，屏幕按**尺寸比例**来适配，不管实际屏幕有多大，NGUI 都会通过合适的缩放来适配屏幕。

| 特性 | 说明 |
|------|------|
| **优点** | 各设备看到的 UI 和屏幕比例始终一致 |
| **缺点** | 高分辨率上 UI 会被放大，有可能模糊 |

---

#### 两种模式对比

| 对比维度 | Flexible（灵活模式） | Constrained（约束模式） |
|------|------|------|
| **缩放依据** | 像素固定 | 比例适配 |
| **低分辨率** | 正常显示 | 等比例缩小 |
| **高分辨率** | UI 显得很小 | UI 等比放大（可能模糊） |
| **适用场景** | 固定分辨率项目、像素风游戏 | 需要跨分辨率保持布局一致的项目 |
| **可控性** | 通过 Min/Max Height 限制范围 | 完全等比，不可控 |

> [!IMPORTANT] 选择建议
> - 如果追求**像素精度**（如像素风格游戏）→ 选 **Flexible**
> - 如果追求**跨设备布局一致**（如手游多机型适配）→ 选 **Constrained**
